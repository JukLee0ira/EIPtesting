# EIP-2935 Test Report

## Overview

This report documents the execution results of the built-in **EIP-2935 test suite** in this repository.
The suite covers and verifies the core behaviors introduced/required by EIP-2935, including:

## 测试计划

### 一、核心功能测试

#### 1.1 历史存储合约部署测试

**测试目标**：验证历史存储合约是否正确部署在指定地址

| 测试项 | 测试描述 | 预期结果 |
|--------|----------|----------|
| 合约地址验证 | 检查 HISTORY_STORAGE_ADDRESS (0x0000F90827F1C53a10cb7A02335B175320002935) 是否存在 | 合约地址存在且具有正确代码 |
| 合约字节码验证 | 验证部署的字节码符合规范 | 字节码与规范中定义的一致 |
| 合约Nonce验证 | 确认合约Nonce为1 | Nonce值为1 |
| 账户 exemptions | 验证合约账户是否豁免EIP-161清理 | 账户状态符合系统合约特征 |

#### 1.2 环形缓冲区存储测试

**测试目标**：验证环形缓冲区存储逻辑的正确性

| 测试项 | 测试描述 | 预期结果 |
|--------|----------|----------|
| 缓冲区大小 | 验证环形缓冲区大小为8191 | size = HISTORY_SERVE_WINDOW = 8191 |
| 写入位置计算 | 验证 (block.number-1) % 8191 正确计算存储位置 | 位置计算正确 |
| 循环覆盖逻辑 | 验证缓冲区满后正确覆盖旧数据 | 旧数据被正确覆盖 |
| 初始状态 | 验证激活时的初始存储状态 | 初始状态符合预期 |

#### 1.3 父区块哈希写入测试

**测试目标**：验证区块处理时父区块哈希的正确写入

| 测试项 | 测试描述 | 预期结果 |
|--------|----------|----------|
| 系统调用触发 | 验证每个区块开始时触发系统调用 | 系统调用正确执行 |
| 输入数据 | 验证调用时传递的calldata为block.parent.hash | 输入数据正确 |

| 写入时机 | 验证写入发生在交易处理之前 | 写入顺序正确 |
